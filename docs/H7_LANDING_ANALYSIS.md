# H7: 風ありの小さな足場への自動着地 — 原因分析・試した設計・結論

結論を先に: **H6 より確かに良くなったが小さい(全足場の合計で +0.3〜1.6 ポイント(+17/1535、+5、+25、+15、+5 件)、5つの風条件のすべてで同方向)。小足場80%は未達。**
大きく見えた改善(+7%)は、調整に使った1つの風条件(270°・3 m/s)だけの過学習で、別の風向・風速では効果が消え、衝突が増えたので撤回した。

## 1. 原因分析(`tools/autoland_miss.ts` / `autoland_stall.ts` / `autoland_trace.ts`)
失敗した試行を「最接近の瞬間」で分類した(風 270°・3 m/s・突風 0.3、試行番号 1000〜1199。H6 時点)。
| 足場 | 失敗の内訳(最接近の時点) |
|---|---|
| 電柱 | 最接近で既に面より低い 25／高すぎて通過 25／横に外した 18 |
| 看板 | 近くまで来たが止まれず 14／低い 10／横 8／高すぎ 8／速すぎ 6 |
| ベンチ | 横に外した 39(+衝突 4)／速すぎ 4／高すぎ 3 |
| レール | 低い 13／横 13／衝突(高すぎ・速すぎ)17 |
| ベランダ | 近くまで来たが止まれず 22／横 19／衝突(高すぎ)8 |
- 「面より低く沈む」の主因は、**失敗した後で起きる結果**で、原因は手前の「横にずれた・高すぎる・速すぎる」。小さな足場に最終進入で合わせられず、旋回で失速して沈む。
- 失速(stall)は成功した試行でもほぼ全部で起きる(電柱 105/105)。失速そのものは失敗の指標ではない。失速が足場の手前 3 m で起きると失敗、成功では 7 m 地点で起きることもある — 差は「失速の有無」でなく、その時の位置関係。
- 追い風のときの対地速度は、対気速度より遅い。H6 の制御は対地速度で羽ばたき・減速を決めている(下の案Aで検証)。

## 2. 試した設計案と結果
評価は2種類: 調整用(`tune` 0〜59)と、H6 と同じ測定条件(`measure` 1000〜1199)、さらに調整にも H6 比較にも使っていない `holdout`(5000〜5199)を、風を変えて5条件で測った。

| 案 | 内容 | 270°/3m/s(調整した条件) | 別の風4条件 | 結論 |
|---|---|---|---|---|
| A | 羽ばたき・減速の判断を対気速度で行う(追い風の失速を避ける) | +24 | 90°/5: −13、180°/4: **−111**、270°/6: +9(衝突 52/47/96/80、H6 は 39/44/63/61) | **撤回**。風向によって大きく悪化し、衝突も増えた |
| B | 最終進入の手前(6 m)で「横ずれ>1.5 m・高さ超過>2 m」を見て、沈む前にやり直す | +21 | 90°/5: −66、180°/4: +35、270°/6: **−66**(衝突 58/65/76/82) | **撤回**。風によって大きく悪化 |
| A+B | 両方 | **+108/1535 (+7%)** | 90°/5: +6、180°/4: −7、270°/6: +18(衝突 +40〜80%) | 調整した条件でだけ良く見え、他では差がなく衝突が増える。**過学習として撤回** |
| C | 外した後(遠ざかった・面より低い・危険で中止する場面)に、回り込んでやり直す(最大2回、看板・電柱・枝・岩・柵・壁のみ。回り込める空きが確かめられたときだけ) | +17 | 90°/5: +5、180°/4: +25、270°/6: +15、風なし: +5 | **採用**(全5条件で改善、衝突は +1〜10) |
| D | 細い足場で進入速度を下げる(H6 で試験) | 電柱が悪化 | — | 撤回 |
ベンチは、低くて壁際にあり、失敗の多くは「危険の検出による中止」と横ずれ。やり直しを入れると衝突が 4→9 に増えたので、**ベンチは対象から外した**。未解決。

## 3. 採用した変更(`src/autoland.ts`)
- `goArounds: 2`、`goAroundKinds` を看板・電柱・枝・岩・柵・壁へ拡大。
- `dangerGoAround`: 前方の建物で中止するはずの場面でも、回り込む空きがあれば中止せず上がって回り込む。
- `goAround` は、足場から `maxRange`(18 m)より遠いときはやり直さない(遠く離れたら中止、という従来の仕様を維持)。
