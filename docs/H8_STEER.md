# H8-A: 単一◎の操縦 3 方式(比較試作)

**実機(Pixel 7a)での操作感は未確認。** 自動テスト(実タッチを模した入力)で、旋回・上下・斜め・無操作・タップ・連打・長押し・地上・マルチタッチ・低FPSを確かめた段階。

## 切り替え方(再読込なし)
- 上のボタン列の **「操縦 …」** を押すたびに 従来 → A → B → C → 従来。設定画面(⏸)にも同じ選択肢と **「同じ位置から開始」**(固定の開始位置・向き・速さに戻す。3 方式を同じ条件で比べる用)がある。
- 片手操作(右手/左手)のときだけ使われる。**両手操作では従来のスティックのまま**(「操作」で右手/左手にする)。
- 選んだ方式は保存され、次回起動でも復元される。画面左下に現在の方式が小さく出る。◎は 1 つだけ(従来の巡航◎・近接◎は出ない)。
- 切り替えの瞬間に、押している指・ブレーキ・タイマーはすべて解除される。

## 共通の動き(3 方式とも同じ物理・同じ補助の上に、入力の読み取りだけが違う)
| 操作 | 動き |
|---|---|
| ◎の上下 | 上=上昇、下=降下(◎の中心からの距離が大きいほど強い。上限は上昇約17°・降下約25°) |
| ◎の左右 | 触れ始めの機首の向きから、右の指なら右へ・左の指なら左へ曲がる(端で約110°)。なめらかに回り(入力の変化に上限)、急には回らない |
| 斜め | 上と左右の組み合わせ |
| 離す/無操作 | セミオート: 向きを保ち直進、高度は既存の補助が維持(長く離すとゆっくり降下) |
| 短いタップ | 羽ばたき(加速) |
| 連打 | 1.2 秒に 3 回で羽ばたきを 0.7 秒続ける。速さは 15 m/s で頭打ち |
| 長押し(ブレーキ) | 方式ごとに違う(下表) |
| 地上 | 同じ◎で向き直って前進歩行(後退しない)。上=小ジャンプ、短いタップ=羽ばたき(小ジャンプ→離陸) |
| 自動着地の進入中 | 方向の指示は使わず、指が大きく動く/タップすれば従来どおり手動へ戻る |

## 方式ごとの違い
| | A スワイプ指定 | B 動かして操舵 | C 中心でブレーキ |
|---|---|---|---|
| 進路が決まる時 | スワイプして**離した時** | 指が**動いている間**更新 | 周辺を**押している間**更新 |
| 離したあと | 決めた進路へ向き、その後直進 | 指の目標へ向き、その後直進 | 同左 |
| ブレーキ | 動かさず 0.3 秒押し続ける | 動かさず 0.3 秒、または動かしたあと**止まって 0.65 秒** | **中心**を 0.3 秒押し続ける(周辺で止まってもブレーキしない) |
| 誤判定の対策 | 16 px 以上動けばスワイプ(ブレーキにならない) | 6 px 未満の揺れは「止まっている」扱い。描画が固まった時間は数えない | 周辺を押してから 0.14 秒たつまで進路を更新しない(タップで進路が動かない) |
- 描画が重いとき(1 フレームが長いとき)は、ブレーキ判定の長さを「1 フレームの長さ×6」まで自動で延ばす(指を離した通知が遅れて届いても、タップを長押しと誤判定しない)。H6 の短タップ補償(固まった時間を引く)も維持。
- 上下は、飛行経路を追いかける制御にすると失速ぎみのときに機首を引き続けて失速から出られなくなったため、**指の角度に比例した操舵**にしている(速さが足りないと上昇の目標を自動で弱め、上昇には自動で羽ばたく)。

## Pixel 7a での比較手順
1. 右手/左手にする → 「同じ位置から開始」で固定の開始へ → 「操縦」を A にして、右へスワイプして離す/上へスワイプ/タップ連打/長押し。
2. 「同じ位置から開始」→ B、→ C と、同じ動きで比べる。見る点: ふらつき(左右の振れ・カメラ)、加速のしやすさ、制動のしやすさ、着地のしやすさ。
3. 地上に降りて、同じ◎で向き直って歩く・上で小ジャンプ・タップで離陸。
4. 従来に戻して、これまでの操作が変わっていないこと。
