# オートパイロット長時間耐久試験(監査対応)

`tools/autopilot_endurance.ts` が、ゲーム内30分 × 4行動方針 × 3シード = 12本(計360分)を、実機と同じ固定60Hzの物理で描画なしに実行して数える。

    npx esbuild tools/autopilot_endurance.ts --bundle --platform=node --outfile=dist-test/endurance.cjs && node dist-test/endurance.cjs 30 3

定義: **クラッシュ**=Flight.crashes の増加(壁に当たった後の落下の着地衝撃も1回と数える) / **テレポート**=最終手段の再配置(`stats.teleports`) / **重大な固着**=休憩・歩行以外の状態のまま20秒間で5m未満しか動けなかった窓の数 / **マップ逸脱**=|x|または|z|>205。

## 変更点
- **テレポート廃止→段階的復帰**: 固着は `recover()`(離陸のやり直し・向き替え・目標の再選択。位置・速度・統計に触らない)を3秒ごとの見張りで繰り返す。約42秒(見張り14回)連続で動けない場合のみ `rescue()`。`rescue()` は同じ水平位置のまま周囲の建物より上へ持ち上げ、位置・速度・飛行モード・気絶/ジャンプ/止まり木だけを書き換える。`Flight.reset()` は使わず、クラッシュ数・羽ばたき数などの統計は消さない。
- **着地進入**: 目標までの降下線上に越えられない建物がある場合と、屋根の手前で屋根より1.5m以上低い場合は着地を諦めて高度を取り直す(壁への衝突が主因だった)。
- **離陸**: 近く(18m)の壁に加え、32m先の高い建物を避けて開けた向きへ回ってから飛ぶ。離陸直後は羽ばたきを続けて速度を稼ぐ。
- **遠くの高い建物**: 越えられない高さなら早めに低い側へ緩やかに回る。
- **衝突後の落下**: 気絶が明けた時点で地面が近く落下中なら、機首を上げて羽ばたき、二重のクラッシュ(壁+着地衝撃)を減らす。

## 数値の読み方・限界
- 着地は 242 → 150 に減った(進入を諦める場面が増えたため)。方針差は維持: 自然生活の地上滞在は約41%、景色観賞は約2%、冒険探索は約16%(電線あり)。
- クラッシュは 0 にならない(30分で平均4回)。上げ下げの多い進入と建物密集地での回避は、このモデルでは完全には避けられない。
- 試行錯誤の記録: 回り込みを強めすぎる(曲がり0.85・先読み56m)とクラッシュが18〜38回/本に悪化したため取り下げた。進入の許容を厳しくしすぎると着地が98回まで減りクラッシュ削減も小さかったため、降下線判定を緩めて採用した。
